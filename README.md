# แปลงรายงาน ACC → ตารางข้อมูล

เว็บแอปสำหรับแปลงรายงานจากระบบบัญชี (ขายสด / ขายเชื่อ / รับคืน-ลดหนี้)
ที่อยู่ในรูปแบบหลายบรรทัด/มีหัวรายงาน ให้กลายเป็น **ตารางแบบแบน 13 คอลัมน์**
พร้อมนำไปวิเคราะห์ต่อใน Excel / Power BI / Pivot ได้ทันที

ประมวลผลทั้งหมด **ในเบราว์เซอร์** — ไฟล์ไม่ถูกอัปโหลดขึ้นเซิร์ฟเวอร์ จึง deploy
เป็น static site บน Vercel ได้ฟรีโดยไม่ต้องมี backend

## คอลัมน์ผลลัพธ์

`รหัสลูกค้า · ชื่อลูกค้า · วันที่เอกสาร · เลขที่ใบกำกับ · รหัสสินค้า · ชื่อสินค้า · จำนวน · หน่วยนับ · ราคา/หน่วย · เงินก่อนภาษี · ภาษีขาย · จำนวนเงิน · รวมทั้งสิ้น`

## เทคโนโลยีที่ใช้

| ส่วน | เครื่องมือ |
|------|-----------|
| Framework | Next.js 16 (App Router) — static export |
| ภาษา | TypeScript |
| UI | Tailwind CSS v4 + lucide-react |
| ฟอนต์ | Sarabun (next/font, รองรับไทย) |
| อ่าน/เขียน Excel | SheetJS (`xlsx`) ฝั่ง client |
| Deploy | Vercel |

## การทำงานของ parser (สรุป)

- รายงาน 3 ประเภทมี **ตำแหน่งคอลัมน์ต่างกัน** → ระบบ map คอลัมน์จาก **ข้อความหัวตาราง**
  (เช่น `รหัสสินค้า`, `เงินก่อนภาษี`) ไม่ใช่ index ตายตัว
- ยอดระดับเอกสาร (เงินก่อนภาษี / ภาษีขาย / รวมทั้งสิ้น) ใส่เฉพาะ **บรรทัดสินค้าแรก**
  ของแต่ละใบกำกับ
- **รับคืน/ลดหนี้**: ติดลบทุกค่าตัวเลข และตั้งภาษีขายเป็น 0 เมื่อไม่มีค่า
- ไฟล์ขายเชื่อ/รับคืนจาก ERP เก็บข้อมูลไว้ใน "Preamble" ของไฟล์ .xls — ระบบ fallback
  ไปอ่านอัตโนมัติ

> ความถูกต้องตรวจสอบแล้วเทียบกับไฟล์ "หลังจัดเรียง" จริง: ขายสด 876/876 แถวตรงเป๊ะ,
> รับคืน 7/7 ใบตรงเป๊ะ, ขายเชื่อตรงทุกใบที่อยู่ในทั้งสอง snapshot

## แพตช์ SheetJS (สำคัญ)

ไฟล์ .xls จาก ERP นี้ใช้ number format แบบ `###,###,###,##0` ซึ่งทำให้ SheetJS
เวอร์ชันปกติ throw และอ่านไม่ได้ทั้ง sheet — แก้ด้วย [`patch-package`](./patches/xlsx+0.18.5.patch)
ที่ normalize format ก่อนประมวลผล แพตช์จะถูกใช้อัตโนมัติผ่าน `postinstall` ทุกครั้งที่ติดตั้ง
(รวมถึงตอน build บน Vercel)

## รันบนเครื่อง

```bash
npm install      # postinstall จะ apply patch ให้อัตโนมัติ
npm run dev      # http://localhost:3000
```

## Deploy บน Vercel

1. push โปรเจกต์นี้ขึ้น GitHub
2. ที่ [vercel.com](https://vercel.com) → **Add New → Project** → เลือก repo
3. Vercel ตรวจจับ Next.js อัตโนมัติ ไม่ต้องตั้งค่าใด ๆ (ไม่มี env vars)
4. กด **Deploy**

หรือ deploy ตรงจากเครื่อง:

```bash
npm i -g vercel
vercel
```
